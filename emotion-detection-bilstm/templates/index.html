ABOUT THE PROJECT

A complete B.Tech CSE deep-learning project.

This project combines NLP preprocessing, Keras/TensorFlow deep learning, Flask APIs and a responsive frontend. The training script saves the model, tokenizer and label encoder so the same pipeline can power the website.

PythonTensorFlowKerasFlaskHTML/CSS/JSScikit-learn
LIMITATIONS

Read predictions responsibly.

Sarcasm, slang, spelling errors, code-mixed language and ambiguous sentences can fool the model. It only predicts categories represented in its training data and can reflect dataset bias.

This project detects patterns in text. It is not a medical or psychological diagnostic system.
